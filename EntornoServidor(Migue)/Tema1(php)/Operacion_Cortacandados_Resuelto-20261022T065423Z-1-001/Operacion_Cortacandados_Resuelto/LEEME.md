# Operación Cortacandados · DWES UD1

1. Copia la carpeta `Operacion_Cortacandados` dentro de `C:\xampp\htdocs`.
2. Inicia Apache desde XAMPP. No es necesario iniciar MySQL.
3. Abre `http://localhost/Operacion_Cortacandados/denuncia.html`.
4. La aplicación tiene dos PHP para completar: `generarExpediente.php` y `analizarExpediente.php`.
5. `denuncia.html` y `datosRobo.php` ya están terminados; no cambies el catálogo.

Recorrido: `denuncia.html` -> `generarExpediente.php` -> `analizarExpediente.php`.

No hay CSS, JavaScript, base de datos ni sesiones. Trabaja siguiendo `ENUNCIADO.md` o `ENUNCIADO.pdf`.
