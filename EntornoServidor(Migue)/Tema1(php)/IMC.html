# 03 · Formulario de datos personales ## Objetivo Completar un formulario HTML con controles de distintos tipos y procesar sus datos desde PHP mediante **POST**. ## Actividad Completa `radioCheckbox.html` con todos estos campos, manteniendo los nombres indicados para que PHP pueda recuperarlos: | Campo / `name` | Control y opciones | | --- | --- | | `nombre` | Texto de máximo 20 caracteres. | | `apellidos` | Texto de máximo 20 caracteres. | | `edad` | `select` con «Menos de 20 años», «Entre 20 y 39 años», «Entre 40 y 59 años», «60 años o más»; utiliza esos mismos textos como valores. | | `peso` | Número en kg con decimales, de 20 a 500. | | `sexo` | Radio con valores `masculino` y `femenino`. | | `estado-civil` | Radio con valores `soltero`, `casado` y `otro`. | | `aficiones[]` | Checkbox con valores `cine`, `literatura`, `tebeos`, `deporte`, `musica`, `television`. | Incluye botones **Enviar** y **Borrar**. El formulario debe enviar por `POST` a `porcesarDatos.php` (conserva el nombre de archivo indicado). Completa `porcesarDatos.php` para leer los campos, comprobar que los obligatorios y las opciones seleccionadas son válidos, mostrar nombre y apellidos en un `

`, edad, peso, sexo y estado civil en párrafos, y las aficiones seleccionadas en una lista `
    `. Si no se marca ninguna afición, muestra un mensaje en lugar de generar errores. ## Prueba Envía el formulario con una afición, con varias y sin ninguna. Comprueba que al pulsar **Borrar** se limpian los controles y que el resultado no muestra código HTML introducido en los campos de texto. **Pistas del temario:** `$_POST`, `select`, radio, checkbox con `[]`, `isset()`, `foreach` y `htmlspecialchars()`.
